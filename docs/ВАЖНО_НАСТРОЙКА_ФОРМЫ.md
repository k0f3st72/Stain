# ВАЖНО: Настройка формы контактов

## Текущее состояние

Форма уже подготовлена для работы через **Formspree**.

В файле `index.html` (строка 364) есть:
```html
<form class="contact-form" id="contactForm" action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

## ЧТО НУЖНО СДЕЛАТЬ (один раз):

### 1. Зарегистрируйтесь на Formspree
- Перейдите: https://formspree.io/
- Создайте бесплатный аккаунт (50 отправок/месяц бесплатно)

### 2. Создайте новую форму
- Нажмите "+ New Form"
- Email для получения заявок: **STA1NPROJ3CTS@gmail.com**

### 3. Получите Form ID
После создания формы вы получите ID в формате: `xabc1234`

### 4. ЗАМЕНИТЕ в index.html

Найдите строку 364:
```html
action="https://formspree.io/f/YOUR_FORM_ID"
```

Замените `YOUR_FORM_ID` на ваш реальный ID:
```html
action="https://formspree.io/f/xabc1234"
```

### 5. Готово!

После этого:
- ✅ Заявки будут приходить на STA1NPROJ3CTS@gmail.com
- ✅ Gmail НЕ отображается на сайте (скрыт)
- ✅ Пользователь останется на сайте после отправки
- ✅ Покажется сообщение "Анкета отправлена"
- ✅ НЕ откроется почтовый клиент
- ✅ НЕ будет редиректа

## Безопасность

✓ Не требует паролей в коде
✓ Работает с frontend-only сайтами
✓ Защита от спама встроена
✓ Email получателя скрыт от посетителей
